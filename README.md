# 水下鱼群智能监测系统

水下视频监测界面的静态前端原型。页面用于展示视频接入、鱼体检测框、11 个关键点与骨架、个体行为，以及四类群体行为统计。

本仓库只包含可在浏览器中打开的界面，不包含检测模型、摄像头服务或推理程序。

## 功能

- **界面演示**：生成标记为「模拟数据」的鱼体、状态和图表，只用于查看交互，不能当作实验结果。
- **本地视频**：播放本机视频；若同时导入逐帧分析结果，则叠加姿态与行为。没有分析结果时只播放视频。
- **本机摄像头预览**：仅显示画面，不执行鱼体识别。
- **状态提示**：活动强度和急转避让占比超过页面阈值时给出提示。阈值只影响界面，不改变原始数据。
- **运行日志**：记录当前页面会话中的接入、提示和停止事件，刷新后即消失。

四类行为名称固定为：低活动、正常游动、快速游动、急转避让。

## 本地打开

无需安装依赖，也没有构建步骤。

演示模式和本地视频可以直接双击 `index.html`。摄像头预览必须通过 `localhost` 或 HTTPS 打开，浏览器才会提供授权。在仓库目录执行：

```bash
python -m http.server 8080
```

然后访问 [http://localhost:8080](http://localhost:8080)。

操作约定：

- **暂停**保留当前画面和分析结果。
- **停止**清空当前结果，并保留已有日志。
- 关键点置信度下限只过滤可视化，不修改导入文件。

## 分析结果格式

`time` 为对应视频播放时间的秒数。`bbox` 使用原始视频坐标，顺序为 `[x, y, width, height]`。每个鱼体提供 11 个关键点，格式为 `[x, y, confidence]`；没有置信度时可以写成 `[x, y]`。

`behavior` 顺序固定为 `[低活动, 正常游动, 快速游动, 急转避让]`，填写比例或数量均可，页面会按总和归一。建议提供与视频一致的 `videoWidth` 和 `videoHeight`，叠加层会按 `object-fit: contain` 对齐留边后的画面。`engine` 和 `latencyMs` 仅在数据中实际给出时显示。

完整示例见 [`examples/sample-analysis.json`](examples/sample-analysis.json)。该文件是合成数据，需要与自己的本地视频按时间轴配合使用；仓库中不附带视频。

```json
{
  "videoWidth": 1280,
  "videoHeight": 720,
  "windowSeconds": 2,
  "engine": "TensorRT FP32",
  "frames": [
    {
      "time": 0,
      "detections": [
        {
          "id": 1,
          "bbox": [180, 160, 120, 48],
          "keypoints": [[190, 184, 0.92], [200, 184, 0.93], [210, 184, 0.94], [220, 184, 0.95], [230, 184, 0.95], [240, 184, 0.94], [250, 184, 0.93], [260, 184, 0.92], [270, 184, 0.91], [280, 184, 0.9], [290, 184, 0.88]],
          "behavior": 1
        }
      ],
      "metrics": {
        "fishCount": 1,
        "activityScore": 0.41,
        "behavior": [0, 1, 0, 0],
        "latencyMs": 7.0
      }
    }
  ]
}
```

个体行为字段 `behavior` 使用 `0` 到 `3` 的序号，或直接使用上述四个中文名称。行为序列、鱼体编号和模型推理需要由外部程序生成。

## 数据边界

前端只读取用户在本机选择的文件，不会把视频或 JSON 发送到网络。接入真实水下摄像头和工控机推理时，需要另行提供视频流、分析结果和控制接口；这些都不在本仓库中。

请不要把现场录像、含有地点或人员信息的文件，以及未公开的实验数据提交到仓库。本地媒体和私有结果已写在 `.gitignore` 中。

## 页面发布

这是纯静态站点。仓库托管到 GitHub 后，可在仓库 **Settings → Pages** 中选择发布分支的根目录。发布地址使用 HTTPS，可以请求摄像头权限；识别仍然不会在页面内执行。
